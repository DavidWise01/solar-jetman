EXPERIMENT REPRODUCIBILITY

See methodology and limits

Both phase hypotheses process the same two samples at 0° and 180°. The opposite-sign model expects fault signal reversal; the invariant model assumes no reversal. A baseline uses only pre-existing alarm/drift evidence. On 24 separate labeled calibration worlds, each candidate must improve mean Brier score with a conservative confidence-margin rule. The chosen model then runs against 100 disjoint held-out worlds. No test truth is passed to the inference operator. Selection is read-only, and the 365-slot controller is never mutated.

Model mismatch, changes after calibration, dependence between samples, real-world calibration accuracy, or adversarial sensors can invalidate this result. No real phase-sensitive sensor has been supplied; this is a software simulation. Calibration policies are issued only in-process and are not cryptographically signed.
